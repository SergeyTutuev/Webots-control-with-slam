# Webots Control with SLAM 🤖

[![ROS 2](https://img.shields.io/badge/ROS-2-blue)](https://docs.ros.org/)
[![Webots](https://img.shields.io/badge/Webots-R2023b-green)](https://cyberbotics.com/)

Реализация **SLAM** (одновременной локализации и построения карты) и **локального планировщика объезда препятствий** для робота в симуляторе Webots с использованием **ROS 2**.

## 📖 О проекте

Проект представляет собой ROS 2‑пакет, который интегрирует симулятор Webots с стеком навигации ROS 2 (Nav2). Основная задача — продемонстрировать работу алгоритмов SLAM и локального планирования в условиях симулированной среды. Робот (автомобильного типа) оснащён лидаром и другими сенсорами, что позволяет ему строить карту окружающего пространства и автономно объезжать препятствия при движении к заданной цели.

[Демо видео](./videos/demo.mp4)

## ✨ Основные возможности

- **SLAM** – построение карты и определение местоположения робота в реальном времени (на основе данных лидара).
- **Локальный планировщик** – объезд статических и динамических препятствий с использованием стека Nav2.
- **Интеграция с Webots** – двунаправленный мост между контроллерами Webots и топиками ROS 2.
- **Готовые миры** – несколько предустановленных сценариев (`city_traffic`, `break_room`, `ipr_factory`, `nao_room`) для тестирования.


## 🚀 Установка и запуск

### Предварительные требования

- **ROS 2** (Humble или новее)
- **Webots** (R2023b или новее)
- Пакет `webots_ros2` (устанавливается отдельно)
- Python (>3.8) (numpy, rclpy, cv_bridge)
  
### Сборка пакета

```bash
# Клонируйте репозиторий в рабочее пространство ROS 2
cd ~/ros2_ws/src
git clone https://github.com/SergeyTutuev/Webots-control-with-slam.git

# Соберите пакет
cd ~/ros2_ws
colcon build --packages-select car_pkg

# Подключите окружение
source install/setup.bash

# Запуск проекта
ros2 launch car_pkg launch.py
```
## ⚙️ Конфигурация
Параметры SLAM и локального планировщика задаются в соответствующих узлах (webots_bridge.py, room_navigator.py).
В папке world/ доступны несколько сценариев. Чтобы выбрать конкретный мир, отредактируйте путь к .wbt‑файлу в launch/launch.py или передайте аргумент при запуске (если предусмотрено).
